# AERIS-10 — BETA PCB changelog

All boards under `beta/pcb/<BOARD>/` are **BETA: KiCad 10.0.6-routed/checked copies of the EAGLE conversion in `engineering/PCB/`; DRC-checked; not reviewed by the original designer; not fabricated.** The EAGLE originals (`4_Schematics and Boards Layout/`) and `engineering/PCB/` were not modified. No change below alters the netlist; only routing, placement of parts that were outside the outline, zone fills/priorities, copper-polygon net labels, silkscreen text positions and documentation.

Tooling: `beta/pcb/tools/` (pcbnew Python scripts, `beta_drc.sh`, `beta_export_package.sh`), Freerouting **2.5.0** (`beta/pcb/tools/freerouting-2.5.0.jar`, build 2026-10-05, SHA-256 `f6f51bb02245e8e717f9359bd260cc9c5c0b1bc0acc8b7cb2cd5b8ffeb5de3c7`, run with OpenJDK 27 `java -jar freerouting-2.5.0.jar -de X.dsn -do X.ses -mp N -mt 8 -l en`; the `-oit` flag of older versions no longer exists in 2.5.0 `--help`), KiCad Python 3 (pcbnew: `ExportSpecctraDSN`, `ZONE_FILLER` via `kicad-cli pcb drc --refill-zones --save-board`).
